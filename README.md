# Kritica & Ashish — The Corbett Wedding

A cinematic, mobile-only destination wedding invitation for **Kritica Dwivedi & Ashish Pandey**, 24–26 November 2026 at Wyndham Garden, Ramnagar, Jim Corbett National Park.

## Stack

- React + Vite
- GitHub Pages
- Custom domain target: `kritica.in`
- CSS-first animation and editorial layout
- Web Audio procedural forest/river atmosphere with a tiger-snort cue
- WhatsApp-first RSVP with optional structured endpoint hook

## Development

```bash
npm install
npm run dev
npm run build
```

## Project rules

`PROJECT_SOURCE.md` is the implementation source of truth. Locked names, dates, event titles, hashtag, visual direction, bilingual behaviour, side-personalisation and mobile-first rules must not be changed casually.
