# Wedding Gallery Drop Zone

Add final wedding/couple photographs here as WebP files using contiguous two-digit names:

`gallery-01.webp`
`gallery-02.webp`
`gallery-03.webp`
...
`gallery-20.webp`

The website auto-discovers files in numerical order up to 20 and stops at the first missing number. Keep numbering contiguous. No JavaScript or React edit is required when adding or replacing photographs.

Until `gallery-01.webp` exists here, Module 18 falls back to the approved gallery images already rendered by the invitation.

Recommended export for mobile: WebP, long edge roughly 1800–2200 px, visually high quality, preferably under ~450 KB per image where practical.
