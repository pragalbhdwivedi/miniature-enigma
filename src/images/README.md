# Wedding image asset structure

Use this folder for final local production imagery. Prefer transparent PNG only where transparency is required (tiger engravings, cutouts, overlays). Prefer WebP/AVIF for full-frame photography once final assets are approved.

## Folders

- `tiger/` — tiger medallions, engraved overlays, reveal cutouts
- `bride/` — Kritica-only photography
- `groom/` — Ashish-only photography
- `couple/` — Kritica + Ashish together
- `destination/` — Jim Corbett / Wyndham Garden / forest / river imagery

Do not rename approved files after they are wired into the site. Keep filenames lowercase and kebab-case.
