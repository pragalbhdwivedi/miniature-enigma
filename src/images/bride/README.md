# Bride assets — Kritica

Recommended production filenames:

- `bride-portrait-main.webp` — primary editorial portrait
- `bride-portrait-detail.webp` — close/detail portrait for story/editorial use
- `bride-family-intro.webp` — bride-side family introduction image
- `bride-mehendi.webp` — Mehendi chapter image when final photography exists
- `bride-haldi.webp` — Haldi chapter image when final photography exists
- `bride-jaimal.webp` — Jaimal / reception chapter image when final photography exists

Use `.webp` or `.avif` for photography unless transparency is actually required.
